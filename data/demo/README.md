# Synthetic demo fixture

`transactions.csv` is a deterministic, entirely synthetic 22-product transaction fixture generated by `scripts/generate_demo.py`. It contains 52 complete Monday–Sunday weeks, one intentionally intermittent product, missing customer IDs, a cancellation, and a return row. It is not UCI Online Retail data and its calculated metrics must only be described as synthetic-demo results.

Regenerate it with `python3 scripts/generate_demo.py`, then build actual local model and evaluation artifacts with `uv run demandsense build-demo` from `apps/api`.
